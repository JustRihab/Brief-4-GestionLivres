# Book Manager

## Description
Book Manager is a simple web application that allows users to manage their personal book collection.

## Features
- Add new books.
- Display the list of books.
- Search books by title or author.
- Sort books by title, author, or year.
- Edit and delete books.
- Save books using LocalStorage.

## Technologies
- HTML5
- Tailwind CSS
- JavaScript (ES6 Modules)
- LocalStorage

## Project Structure
- `index.html` – Main page.
- `src/app.js` – Application logic.
- `src/ui.js` – User interface.
- `src/state.js` – Application state.
- `src/utils.js` – Utility functions.

## How to Run
1. Clone or download the project.
2. Open the project folder in VS Code.
3. Run the project using Live Server.
